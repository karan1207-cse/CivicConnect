# CivicConnect

CivicConnect consists of a React/Vite frontend and a Spring Boot backend.

## Backend

The backend uses Java 21 and Maven. No authentication is configured yet.

From the repository root, build and test the backend with:

```shell
cd backend
mvn test
```

Run the backend locally with:

```shell
mvn spring-boot:run
```

## Frontend

Install the frontend dependencies and start Vite with:

```shell
npm install
npm run dev
```
